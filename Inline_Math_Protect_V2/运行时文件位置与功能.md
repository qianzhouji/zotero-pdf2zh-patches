# PDF2zh 本机补丁：运行时文件位置与功能

本文列出 Inline Math Protect、Citation Protect 和 Reference Skip 相关的六个 BabelDOC 运行文件。刚核对时，Inline Math Protect V2 管理器报告其五个文件均为 V2；Reference Skip 的术语抽取器也与补丁归档中的当前源码一致。

## BabelDOC 运行目录

```text
<PDF2ZH_ROOT>/server/zotero-pdf2zh-next-venv/lib/python3.12/site-packages/babeldoc/format/pdf/
```

PDF2zh/BabelDOC 从这些固定的 Python 包路径导入模块。请保留文件名和子目录结构，不要将运行文件移出当前目录。

## 运行文件清单

| 相对路径 | 相关功能 |
|---|---|
| `document_il/midend/il_translator_llm_only.py` | **Citation Protect**：在模型输入中保护数字型上标引用标记，检查返回标记数量和顺序，再恢复原占位符；异常时安全回退。**Reference Skip（主翻译）**：参考文献标题仍可翻译，条目跳过主翻译；检测后续章节或布局信号后恢复翻译。**Inline Math Protect V2**：对数学与引用标记做联合校验、受控重试，并在失败时恢复原段落。 |
| `document_il/midend/automatic_term_extractor.py` | **Reference Skip（术语抽取）**：让参考文献条目也跳过自动术语抽取；参考文献后识别到附录、补充材料、图表说明或其他后续章节时恢复术语抽取。 |
| `document_il/midend/styles_and_formulas.py` | **Inline Math Protect V2**：从 PDF 字符和版面信息识别行内数学；保留小数、变量、特殊字体字形、公式边界和上下标位置；阻止跨说明文字合并公式；将跨物理行公式拆分。 |
| `document_il/utils/inline_math_protect.py` | **Inline Math Protect V2 辅助模块**：生成/检查数学和引用保护标记、管理受控片段重试及审计记录，并过滤完全落在可见页面范围之外的文字。 |
| `document_il/utils/layout_helper.py` | **Inline Math Protect V2**：修正文本框与字符匹配的优先级，避免标题框边缘抢走正文字符而造成句子碎片或重叠。 |
| `new_parser/native_parse.py` | **Inline Math Protect V2**：在新解析器生成中间表示后，过滤完全位于页面可见范围之外的字符，避免裁剪 PDF 隐藏内容进入翻译。 |

各路径都以前面的 BabelDOC 运行目录为根。例如主翻译器完整路径为：

```text
<PDF2ZH_ROOT>/server/zotero-pdf2zh-next-venv/lib/python3.12/site-packages/babeldoc/format/pdf/document_il/midend/il_translator_llm_only.py
```

## 补丁归档副本

- `payload/`：Inline Math Protect 安装器使用的五个源码副本。`il_translator_llm_only.py` 是包含已有 Citation Protect 和主翻译 Reference Skip 的完整文件。
- `../Citation_Protect/`：独立 Citation Protect 历史快照和差异；当前功能已并入主翻译器。
- `../Reference_Skip/payload/automatic_term_extractor.py`：自动术语抽取器的 Reference Skip 当前源码副本。
- `baseline/`：Inline Math Protect 安装前的四个基线文件。主翻译器基线保留先前已安装的 Citation Protect 和 Reference Skip。
- `../Reference_Skip/baseline/automatic_term_extractor.py`：自动术语抽取器安装 Reference Skip 前的本机备份。
- `diffs/` 和 `../Reference_Skip/diffs/`：审阅各自代码改动的 unified diff。

运行时导入的是虚拟环境中的文件，不是归档副本。

## 移动、安装与卸载

移动本补丁目录中的文档或归档副本不会改变当前插件，也不需重跑翻译。运行时文件不能移出其 BabelDOC 子目录，否则 Python 导入会失败。

`manage.py install/remove` 只管理 Inline Math Protect V2 的五个文件；卸载时会保留 Inline Math 安装前基线已有的 Citation Protect 和主翻译 Reference Skip。自动术语抽取器的 Reference Skip 是单独归档的运行代码，不由该 `manage.py` 管理。新开始的任务会使用运行目录中的已安装代码，已生成的 PDF 不会自动重译。
